Public mirror of selected notes from a private Obsidian vault. Content syncs automatically on every push to the private parent repo.

## About

Everything in this repo is published from a dedicated `SharedResources/` folder in a private notes vault. The mirror is one-way: this repo receives, nothing is pushed back upstream.

If you spot an error or want to suggest a resource, open an issue.
